## Recommendation on a rank-local routing GPU run

`negctrl_ranklocal_routing.py` on TP4 B1 is safe (identical raise on every rank before the forced references, 3.4 s on the CPU) and would exercise the cross-rank route-consistency branch of `compare()` under NCCL, which no run has hit yet. It would not add anything about attribution: the expected outcome is the same `expert_ids: … different between ranks` message on all four ranks with no `rank N:` prefix, which this step and the CPU run already predict. Worth running only if coverage of that branch on real hardware is wanted; not needed to establish the evaluator behaviour, which the CPU run and the two GPU immutability runs already pin down.

## Unresolved evaluator robustness issues (summary; details in ISSUES.md)

1. Device checksum is linear and not adversarial (item 17): tensors above 64 MB are summarised by a plain int32-word sum and a position-weighted sum with weights `(i mod 65521) + 1`, both exact int64; two word changes `+d` at word `i` and `-d` at word `i + 65521` leave both sums unchanged, so a deliberately crafted mutation of a large input is not detected. Random or single-element corruption is detected (Steps 6, 7, 8). Tensors of at most 64 MB are compared exactly on the host.
2. Group-wide errors carry no offending-rank attribution (item 15): output corruptions are graded on all-reduced quantities and routes on an all-reduced checksum, so `ranks[].reason` is the same on every rank; only a rank's own local error gets a `rank N:` prefix (this step).
3. Pre-collective rank-local exceptions can hang the group (item 16): structural checks at the top of `compare()` raise on one rank before the first grading collective; the others enter the collective and wait for the 10-minute process-group timeout. Not tested on a GPU on purpose.
4. `agree()` turns any exception into `incorrect` (item 14): every rank-local error string, whatever its class, becomes an AssertionError on every rank, so the distributed path has no `error` status for infrastructure or candidate crashes.

Arm `A2` = overlays `["A1", "A2"]` (`arms/A2.toml`). `overlays/A2/` adds knowledge only; no tool or
prompt changes. Generic: no DSv4.1 shapes, layouts or code.

## How the B300 rows were made
`primbench_b300/run_seed.sh build OUT` (CPU), then `run OUT g1..g4`, each group under its own 1-GPU lease
(`gpu_lease run --gpus 1`), all 4 groups finished in < 1 min each; `run_seed.sh rows OUT` -> rows.
Porting change: only `tc_mma.cu` needed a guard (`ptxas: Feature '.kind::i8' not supported on .target 'sm_103a'`).
All 3,133 rows pass `megabench.primdb.validate`.

## Known limits
- The GEMM is not tuned per shape; no BF16->MXFP8 activation quantizer is included.
- primbench rows are single runs on one GPU of this node (clock 2032 MHz); notes inside some rows still
  say "sm_100a" because the bench sources print that text.
- The multi-gpu-sync example runs on one GPU (blocks as ranks); the NVLink/multicast snippets are cited
  from SGLang/FlashInfer, not executed here.
- `progress/microbench/primdb_local.jsonl` is 3.5 MB and is part of the workspace's source tree
  (snapshots include it; it compresses ~10x).

## GPU time used (builder-a2)
About 25 GPU-minutes on single-GPU leases (primbench 4 groups ~1 min; GEMM tests/benchmarks/A-B ~20 min;
sync example < 1 min) plus one ncu run (< 1 min). No 8-GPU leases.
